## Summary
During the investigation of case DIVD-2026-00014 where two new CVE's identified.
- CVE-2026-102489 - In Zammad versions 6.3.0 to 6.5.4 are vulnerable a remote code execution as a Zammad user which can be used for session leakages. The vulnerability is also present in version 7.0.0 to version 7.1.3 as well, but not exploitable due to environment conditions.
- CVE-2026-102490 - In all versions of Zammad including the latest alpha has an vulnerability been found which enables the local Zammad user to escalate privileges to root.

## What you can do
We advice all users of Zammad to upgrade to the latest version of Zammad or take it offline.

## What we are doing
DIVD is actively scanning and alerting owners of vulnerable Zammad instances.
